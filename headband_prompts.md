## 🛠️ 設計師使用指南 (How to Work with These Prompts)

1. **挑選樣態**：根據所需用途（如 2D 商標選「樣態一」、3D 主圖選「樣態二」）。
2. **生成素材**：將 Prompt 直接輸入 **Lovart**、**Midjourney v6** 或 **Imagen 3**。
3. **向量與組裝**：
   * 將最符合感覺的圖像用 Illustrator 轉為向量檔 (Trace Vector)。
   * 在中心加上現代無襯線 `DR` 文字。
   * 將 `OS` 扣環與 `DR` 做前後遮擋圖層處理（Sandwich Layer）。

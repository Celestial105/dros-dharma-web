🚀 四步驟快速下載、安裝與啟動

Step 1. 準備基礎環境

  • 前往 Obsidian 官網 下載安裝 Obsidian 筆記軟體。
  • 確保 PC 安裝 Python 3.10+（請務必在安裝時勾選 Add Python to PATH）。
  • 前往 Google AI Studio 申請免費用量 Gemini API Key。

Step 2. 下載 DROS 8.0 專案儲存庫

打開終端機 (Terminal / PowerShell)，執行 Git 複製指令：

git clone https://github.com/Top-Celestial-Company-Ltd/Dharma-Reasoning-Operating-System.git
cd Dharma-Reasoning-Operating-System

Step 3. 載入 Obsidian 並啟用內建「DROS Doctrinal Copilot」外掛

  1. 打開 Obsidian，點選「開啟資料夾作為儲存庫 (Open folder as vault)」，指向下載解壓後的資料夾。
  2. 啟用內建外掛 (免重新下載)：點選左下角設定 (⚙️) -> 關閉安全模式 (Turn off Safe Mode)。
  3. 找到內建外掛 DROS Doctrinal Copilot 並切換為打開 (啟用)。
  4. 點擊外掛旁邊的 ⚙️ 齒輪，在 Gemini API Key 填入您的 Google API Key 即可！

Step 4. (極客選項) 啟動本地 DROS 代理伺服器

若您是想自己修改 Python 核心演算法 (如 Weaver 或 GuardVM) 的開發者：

# Windows 雙擊執行 gemini_proxy.vbs，或終端機執行：
python src/proxy/gemini_proxy.py

並將外掛 API Endpoint 指向 http://127.0.0.1:8080/v1。
